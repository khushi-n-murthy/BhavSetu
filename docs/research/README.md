# Research

Every source behind a number on the website lives in [`apps/web/content/sources.json`](../../apps/web/content/sources.json), with publisher, date and what it supports. The site's research library renders that file, and every stat card links to it; the build fails if a stat cites a source id that is not there.

Add desk research and the problem brochure notes in this folder. Add field notes in [`../field-notes/`](../field-notes/).
